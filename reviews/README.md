# Review-Ordner (v3)

- `second/CASE-ID.coding.yaml`: unabhängig erstellte zweite Codierung nach separatem Blindpaket, ohne Erstcodes.
- `quotes/CASE-ID.quotes.yaml`: unabhängige wortwörtliche Quoteprüfung am tatsächlichen Quellensegment.
- `resolutions/CASE-ID.resolution.yaml`: nur die vom Validator berechneten Meinungsverschiedenheiten.

Review-Artefakte sind **kein** selbstsetzbares Freigabesignal. GitHub CODEOWNERS, Branch Protection, unabhängige Fachprüfung und der geschützte Release-Workflow sind dafür nötig.
